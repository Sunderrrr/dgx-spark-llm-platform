# URL prefixes served by the Rust portal instead of Flask (Rust migration,
# docs/rust-migration.md). One per line. Empty: everything is on Flask.
#
# A prefix is routed for EVERY method, page GETs included (dgx-portal-frontend/
# proxy.ts): never list a prefix that is also a Next page path (/request, /keys,
# /memory, /search…), or the page itself would be sent to the Rust portal.
# Phase 3 (media), read-only routes only: the routes that create or act on jobs,
# and those that return a stored file (media_store may read S3), stay on Flask.
# Not routed yet, on purpose: /api/latency, which measures the Flask process
# itself; and the root page /, which would catch every path.
#
# A trailing `$` names one exact path, not its sub-paths; a `*` segment matches
# any one segment (`/admin/users/*/unblock`).
